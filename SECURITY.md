# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of AI models and agentic workflows very seriously. If you discover a bypass technique, prompt injection evasion vector, or critical vulnerability within this proxy:

1. **Do NOT open a public GitHub issue.**
2. Send a detailed report via private vulnerability disclosure to the maintainer or email: `security@ravishkarathnayaka.dev`.
3. Include:
   - Step-by-step reproduction payload
   - Target guard module bypassed
   - Observed behavior vs. expected block decision
   - Impact assessment

We commit to acknowledging receipt within 48 hours and coordinating a responsible patch release.
