DEFENSE-IN-DEPTH

        
Bidirectional Guardrails Pipeline

        
Every request traverses an optimized, zero-allocation interceptor chain on both inbound ingress and outbound model egress.

      


      

        
        

          

            INBOUND INGRESS
            
Client Request $\to$ Upstream LLM

          

          

            

              
01

              

                
Token-Bucket Rate Limiter

                
Tracks sliding-window requests per minute and 1-second burst rates per IP to neutralize brute-force jailbreaking fuzzers (LLM04).

                Limit: 120 RPM • 25 Burst RPS
              

            


            

              
02

              

                
PII Anonymizer & Reversible Session Map

                
Detects and redacts emails, SSNs, phone numbers, AWS keys, GitHub PATs, JWTs, and credit cards with Luhn checksum verification (LLM06).

                Tokens: <REDACTED_ENTITY_#>
              

            


            

              
03

              

                
Multi-Layered Injection Detector

                
Scans heuristics (DAN, Stan, overrides), ChatML delimiter breakout tags, zero-width steganographic unicode, and base64 payload decoders (LLM01).

                Threshold: 0.60 Composite Score
              

            


            

              
04

              

                
Canary Leak & System Extraction Guard

                
Blocks "repeat system prompt verbatim" and monitors secret canaries (CANARY_SEC_TOKEN_9941a8) against extraction (LLM07).

                Active Canary Monitoring
              

            

          

        


        
        

          

            OUTBOUND EGRESS
            
Upstream LLM $\to$ Verified Response

          

          

            

              
05

              

                
Agentic Tool Call Argument Validator

                
Validates function arguments emitted by agents. Blocks SSRF targeting cloud metadata (169.254.169.254) and directory path escapes (LLM08).

                RFC1918 • Cloud Metadata • Path Traversal
              

            


            

              
06

              

                
Hazardous Shell Output Sanitizer

                
Intercepts dangerous commands (rm -rf /, fork bombs, netcat reverse shells, PowerShell encoded commands) and leaked RSA/EC private keys (LLM02).

                Execution Sanitization
              

            


            

              
07

              

                
Session De-Anonymization (Optional)

                
Optionally re-hydrates masked tokens in responses for verified users, or passes sanitized clean content back to client.

                Context-Preserving Reversal
              

            


            

              
08

              

                
Structured Telemetry & Prometheus Exporter

                
Emits structured audit logs with request ID, client IP, latency, and increments Prometheus metric counters at /metrics.

                JSON Lines • OpenTelemetry Compatible

# Point your client directly to port 8080:
curl -X POST http://localhost:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o",
    "messages": [
      {"role": "user", "content": "Hello! Please summarize this quarterly update."}
    ]
  }'

        


        

          
from openai import OpenAI

# Configure OpenAI SDK client with guardrails proxy base_url:
client = OpenAI(
    base_url="http://localhost:8080/v1",
    api_key="mock-llm-key"  # Or your production API key
)

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "Draft a security policy outline."}]
)
print(response.choices[0].message.content)

        


        

          
import OpenAI from 'openai';

const openai = new OpenAI({
  baseURL: 'http://localhost:8080/v1',
  apiKey: 'mock-llm-key',
});

const completion = await openai.chat.completions.create({
  model: 'gpt-4o',
  messages: [{ role: 'user', content: 'Explain zero-trust networking.' }],
});
console.log(completion.choices[0].message.content);
