# Contextual Integrity Boundaries & Adversarial Suffix Scanner

## Helen Nissenbaum's Contextual Integrity Framework
Prevents confidential context norms (e.g. medical records, financial data, authentication keys) from leaking across domain boundaries into public search engines, webhooks, or third-party plugins.
